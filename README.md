# Auto-type
Roda em quaisquer site que dê para injetar um javascript no console


# 1 Passo
* Clique com o botão direito no site desejado
* E clique em Inspecionar.
* Depois clique em console.
# 2 Passo
* Copie o conteúdo do Autotype.js.
* Depois cole no console.
* Depois clique ENTER.
# OBS
Se o site não der para colar, escreva "allow pasting" e depois tente novamente.
